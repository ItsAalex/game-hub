- Category filtering
- Api calling
- Responsive design

## Installation

### Setup

```bash
# Clone the repository
git clone https://github.com/ItsAalex/game-hub.git

# Navigate to project directory
cd game-hub

# Install dependencies
npm install
```

## Usage

### Basic Usage

```bash
# Command to run the project
npm run dev
```

## Project Structure

```
project-root/
├── public                   # containing vite.svg
├── src/                     # Source code
├── index.html               # Serves as the root container
├── package.json             # Package file with what project needs to work propertly
├── package-lock.json        # Package file with what we have installed
├── tsconfig.json            # TypeScript configuration file for browser
├── tsconfig.node.json       # TypeScript configuration file for node
├── vite.config.ts           # Vite configuration file
└── README.md                # This file
```
